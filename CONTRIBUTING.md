# Contributing

Contributions should be target-agnostic and reproducible.

Do not submit proprietary application code, credentials, device identifiers,
captured user data, target-specific bypasses, or copyrighted application
samples. Tests should use synthetic classes and values.

Every tool change should include:

1. a documented input/output contract;
2. deterministic unit tests;
3. explicit side effects and cleanup behavior;
4. a statement of the supported Android/Frida versions when applicable.
